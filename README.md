# Tire Dot-Matrix Character Recognition System

## 项目概述

本项目旨在实现橡胶胎面上白色点阵字符的自动识别系统。针对工业视觉应用场景，采用传统计算机视觉与轻量级深度学习相结合的混合架构，实现高精度、高效率的字符识别。

## 系统架构

系统采用模块化设计，分为四个核心处理阶段：

### 第一阶段：ROI提取与预处理 (Traditional CV)
- **目标**：剔除白色背景，锁定黑色橡胶区域
- **关键技术**：
  - 全局Otsu二值化：区分白色背景与黑色胎面
  - 轮廓分析：寻找面积最大的矩形区域作为Primary ROI
  - CLAHE增强：解决橡胶表面反光导致的对比度不均问题

### 第二阶段：字符定位与形态学重建 (Traditional CV)
- **目标**：将断开的点阵字符连接为可分割的实体
- **关键技术**：
  - Top-Hat变换：提取黑底上的亮色特征（白色字符）
  - 形态学闭运算：使用水平与垂直核连接点阵字符间的缝隙
  - 自适应阈值分割：将字符从增强后的ROI中分割出来

### 第三阶段：字符分割 (Segmentation)
- **目标**：从字符串中提取单个字符图像（64x64像素）
- **关键技术**：
  - 垂直投影分析：计算像素直方图，寻找字符间的空白列作为切割点
  - 连通域过滤：根据宽高比和面积筛选有效字符，剔除橡胶表面的噪声颗粒
  - 归一化处理：将分割出的单个字符进行Padding和Resize，统一为神经网络输入尺寸

### 第四阶段：CNN识别模块 (Deep Learning)
- **目标**：对36类字符（0-9, A-Z）进行高精度识别
- **关键技术**：
  - 轻量级CNN架构：3层卷积 + 2层全连接，或改良LeNet-5
  - 数据集加载：编写Dataset类加载处理后的字符
  - 推理接口：实现Predictor类，接收分割好的图像并输出字符串结果

### API接口

```python
from tire_ocr import TireOCR

# 创建OCR处理器
ocr = TireOCR(output_dir="output")

# 执行完整四阶段流程
result = ocr.full_pipeline("data/20250115083551210.png")

# 或分步执行
enhanced = ocr.stage1_extract_roi(image_path)      # 第一阶段
binary_chars = ocr.stage2_morphological_reconstruction()  # 第二阶段
char_images = ocr.stage3_character_segmentation()  # 第三阶段
result = ocr.stage4_cnn_recognition(char_images)   # 第四阶段

# 可视化各阶段结果
ocr.stage1_visualize()
ocr.stage2_visualize()
ocr.stage3_visualize()
```

## 技术细节

### 图像预处理创新点

1. **自适应阈值选择**：结合Otsu全局阈值与自适应阈值，根据前景比例自动选择最佳分割策略
2. **双方向形态学闭运算**：水平与垂直方向分别进行闭运算，有效连接点阵字符
3. **动态空白列阈值**：根据图像高度自动调整空白列判定阈值，适应不同分辨率图像

### 字符分割策略

1. **垂直投影分析**：识别字符间的空白列作为切割点
2. **连通域过滤**：基于宽高比和面积过滤噪声
3. **智能归一化**：保持字符宽高比的同时，通过padding居中放置到64x64画布

### 输出结果

所有中间处理结果自动保存到`output/`目录：
- `1_binary.png`: 全局二值化图像
- `2_roi.png`: 提取的ROI区域
- `3_enhanced.png`: CLAHE增强图像
- `4_tophat.png`: Top-Hat变换结果
- `5_morph.png`: 形态学闭运算结果
- `6_binary_chars.png`: 二值化字符图像
- `stage1_result.png`: 第一阶段可视化对比图
- `stage2_result.png`: 第二阶段可视化对比图
- `char_00.png, char_01.png, ...`: 分割后的单个字符
- `char_positions.txt`: 字符位置信息
