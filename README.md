# 轮胎胎面点阵字符识别系统 (Tire OCR)

## 项目概述

本项目针对橡胶轮胎胎面上的白色点阵字符识别问题，实现了一套完整的传统计算机视觉解决方案。系统采用灰度增强、背景校正、阈值分割、形态学处理、投影分析、连通域分析、HOG特征提取和SVM分类器等传统方法，完成了从字符区域提取、字符分割到字符识别的完整流程。

## 执行流程详细说明

### 第一阶段：胎面ROI提取与预处理 (Stage 1)

#### 1. 全局二值化 (Otsu)
**处理方法**: 对原始灰度图像应用Otsu全局阈值分割
**处理目标**: 将图像二值化为黑白两色，胎面区域为黑色(0)，背景为白色(255)
**输出文件**: `output/1_binary.png`
**文件内容**: 全局二值化图像，用于后续的胎面区域定位

#### 2. 胎面区域扫描定位
**处理方法**: 状态机扫描算法，从图像中心向左扫描
- **扫描策略**: 基于每列黑色像素比例进行状态转换
- **编号区域识别**: 黑色像素比例10-90%的区域识别为白色文字区域
- **胎面区域识别**: 黑色像素比例>98%的区域识别为纯胎面
- **空白边缘识别**: 黑色像素比例<5%的区域识别为背景空白
**技术参数**: 连续3列符合条件确认为编号区域右边界，连续5列>98%确认为左边界

#### 3. 边界扩展与裁剪
**处理方法**:
- **左右边界扩展**: 基于编号区域向外扩展50像素，左边界额外扩展整体宽度的20%
- **上下边界扫描**: 从上到下/从下到上扫描，寻找连续5行黑色像素<90%的区域
- **边界扩展**: 上下边界分别向外扩展20像素
**输出文件**:
- `output/2_roi_full.png`: 完整高度的胎面区域（裁剪前）
- `output/2_roi.png`: 裁剪后的胎面区域

#### 4. 图像增强
**处理方法**: CLAHE（限制对比度自适应直方图均衡化）
- **参数**: clipLimit=2.0, tileGridSize=(8,8)
- **目标**: 增强局部对比度，提高白色点阵字符的可见性
**输出文件**: `output/3_enhanced.png`
**文件内容**: 增强后的灰度图像，用于后续的编号区域定位

#### 5. 第一阶段可视化
**输出文件**: `output/stage1_result.png`
**文件内容**: 四子图对比展示原始图像、二值化图像、胎面ROI和增强图像

---

### 第二阶段：标签区域定位与预处理 (Stage 2)

#### 1. 编号区域定位
**处理方法**: 优先使用第一阶段定位的编号区域位置
**备选方法**: 如果第一阶段未定位成功，使用亮度分析方法
- **亮度分析**: 计算每列的平均亮度，寻找明显高于平均的区域
- **区域评分**: 综合宽度、平均亮度和宽度接近40像素的得分选择最佳区域

#### 2. 图像旋转校正
**关键问题**: 原始图像中字符为逆时针旋转90度垂直排列
**解决方法**: 对提取的标签区域ROI顺时针旋转90度
**处理目标**: 将字符变为正常的水平方向排列，从左到右为字符序列总长，上下为字符高度
**输出文件**: `output/4_label_roi_rotated.png`
**文件内容**: 旋转后的彩色标签区域ROI

#### 3. 二值化与形态学处理
**处理方法**:
1. **灰度转换**: 将旋转后的彩色图像转为灰度
2. **CLAHE增强**: clipLimit=3.0, tileGridSize=(8,8)
3. **自适应阈值**: 自适应高斯阈值，块大小21，常数5
4. **颜色校正**: 确保字符为白色(255)，背景为黑色(0)
5. **形态学闭运算**: 3×3椭圆核，连接离散的点阵字符
6. **形态学开运算**: 去除小噪声
**输出文件**: `output/4_label_binary.png`
**文件内容**: 二值化后的标签区域图像，字符为白色，背景为黑色

#### 4. 第二阶段可视化
**输出文件**: `output/stage2_result.png`
**文件内容**: 四子图展示增强图像、标签ROI、二值化标签和增强图像直方图

---

### 第三阶段：字符区域分割 (Stage 3)

#### 1. 连通域分析
**处理方法**:
1. **预处理**: 3×3核的形态学闭运算，确保字符内部连接良好
2. **连通域检测**: `cv2.connectedComponentsWithStats`，8连通性
3. **连通域过滤**:
   - 最小面积: 50像素
   - 宽高比范围: 0.3-3.0（正立字符范围）
   - 最小尺寸: 裁剪后高度和宽度均≥3像素

#### 2. 字符裁剪
**处理方法**:
1. **水平投影裁剪**: 裁剪上下空白，阈值=宽度×5%
2. **垂直投影裁剪**: 裁剪左右空白，阈值=高度×5%
3. **字符提取**: 提取裁剪后的字符区域

#### 3. 字符归一化
**处理方法**: 保持原始宽高比，居中放置到64×64画布
**输出文件**: `output/5_segmented_chars.png`
**文件内容**: 带有边界框的二值化标签图像，绿色框标注分割出的字符区域

#### 4. 第三阶段可视化
**输出文件**: `output/stage3_result.png`
**文件内容**: 四子图展示原始标签图像、带边界框图像、分割字符网格和字符尺寸分布图

---

### 第四阶段：传统字符识别 (Stage 4)

#### 1. 合成数据集生成
**处理方法**: 自动生成包含36类字符的合成点阵字符数据集
- **字符类别**: 数字0-9（10类） + 大写字母A-Z（26类）
- **生成数量**: 每个字符30个样本，共1080个样本
- **生成方法**:
  - 随机选择字体（OpenCV五种字体之一）
  - 随机字体大小：1.5-3.0
  - 随机粗细：1-3像素
  - 添加点阵化噪声：15%像素随机移除
  - 添加高斯噪声：标准差10
  - 形态学腐蚀：模拟点阵字符特征
  - 二值化：阈值127

#### 2. HOG特征提取
**处理方法**: 使用OpenCV HOG描述器
- **窗口大小**: 64×64像素
- **块大小**: 16×16像素
- **块步长**: 8×8像素
- **细胞大小**: 8×8像素
- **方向数**: 9个方向
**特征维度**: 每字符提取1764维HOG特征

#### 3. SVM分类器训练
**处理方法**: 使用OpenCV SVM实现
- **SVM类型**: C-SVC
- **核函数**: 线性核
- **终止条件**: 最大迭代1000次，精度1e-6
- **训练数据**: 1080个合成样本的HOG特征
- **标签映射**: 0-35对应字符"0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ"

#### 4. 字符识别
**处理流程**:
1. 提取分割字符的HOG特征
2. 使用训练好的SVM进行分类预测
3. 将预测标签映射为对应字符
4. 拼接所有预测字符形成最终识别结果

#### 5. 最终结果保存
**输出文件**: `output/6_final_result.png`
**文件内容**: 带有识别结果的标签图像
- **绿色边界框**: 分割出的字符区域
- **蓝色字符标注**: 每个字符上方的识别结果
- **红色结果文本**: 图像顶部的完整识别结果字符串

## 项目特点

1. **纯传统方法**: 不使用任何深度学习框架（如torch），保持轻量化
2. **完整流程**: 实现字符区域提取、字符分割、字符识别的完整流程
3. **方向校正**: 自动识别并校正逆时针旋转90度的字符排列
4. **点阵优化**: 针对点阵字符特点优化分割和识别算法
5. **自包含**: 代码内自动生成合成数据集进行训练，无需外部数据

---

## 注意事项

1. **字符类别**: 仅支持数字0-9和大写字母A-Z，无汉字或其他符号
2. **字符方向**: 系统自动处理逆时针旋转90度的字符排列
3. **点阵特征**: 针对白色点阵字符在黑色胎面上的场景优化
4. **输出目录**: 每次运行会覆盖`output/`目录中的文件
