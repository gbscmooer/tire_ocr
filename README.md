# 轮胎胎面点阵字符识别系统 (Tire OCR)

## 项目概述

本项目针对橡胶轮胎胎面上的白色点阵字符识别问题，设计了一套完整的计算机视觉解决方案。系统采用传统图像处理算法，通过精确的ROI提取、编号区域定位和字符分割，为后续的字符识别提供了高质量的预处理结果。

## 核心算法流程

### 第一阶段：基于二进制图像的ROI精确提取
- **算法目标**：从原始图像中精确提取包含编号区域的胎面ROI
- **关键技术**：
  - 全局Otsu二值化：将图像转换为黑白二值图（胎面为黑色，背景为白色）
  - 状态机扫描算法：从图像中心向左扫描，基于黑色像素比例识别编号区域
  - 多级边界处理：精确确定左右边界、上下边界，并按照经验进行扩展
  
### 第二阶段：编号区域定位
- **算法目标**：在胎面ROI中精确定位白色点阵字符区域
- **关键技术**：
  - 优先使用第一阶段已定位的编号区域位置
  - 备选亮度分析方法：基于3_enhanced.png的列亮度分析寻找高亮区域
  - 自适应二值化：在编号区域内提取白色字符点阵

### 第三阶段：字符区域分割
- **算法目标**：将编号区域中的点阵字符分割为单个字符
- **关键技术**：
  - 垂直投影分析：寻找字符间的空白列作为切割点
  - 点阵字符特征过滤：针对点阵字符特点调整宽高比和面积阈值
  - 归一化处理：将分割出的字符统一为64x64像素尺寸

### 第四阶段：字符识别模块（待实现）
- **计划实现**：基于CNN的字符分类识别
- **字符类别**：36类（0-9数字 + A-Z大写字母）

### API接口

```python
from tire_ocr import TireOCR

# 创建OCR处理器
ocr = TireOCR(output_dir="output")

# 执行完整四阶段流程
result = ocr.full_pipeline("data/20250115083551210.png")
print(f"识别结果: {result}")

# 分步执行各阶段
enhanced = ocr.stage1_extract_roi(image_path)      # 第一阶段：ROI提取
label_binary = ocr.stage2_label_localization()      # 第二阶段：编号区域定位
char_images = ocr.stage3_character_segmentation()   # 第三阶段：字符分割
result = ocr.stage4_cnn_recognition(char_images)    # 第四阶段：字符识别（待实现）

# 可视化第一阶段结果
ocr.stage1_visualize()
```

## 技术亮点

### 1. 精确的ROI提取算法
- **状态机扫描**：从图像中心向左扫描，使用黑白像素比例阈值精确识别编号区域
- **边界条件处理**：
  - 编号区域：黑色像素比例10-90%
  - 胎面区域：黑色像素比例>98%
  - 空白边缘：黑色像素比例<5%
- **经验扩展**：左边界额外扩展整体宽度的20%，确保包含完整胎面

### 2. 智能边界处理
- **上下边界扫描**：从上到下/从下到上扫描，寻找连续5行黑色像素<90%的区域
- **边界扩展**：上下边界分别向外扩展20像素，确保包含完整区域
- **容错机制**：支持未找到明显边界时使用默认值

### 3. 编号区域定位策略
- **优先复用**：优先使用第一阶段已识别的编号区域位置
- **亮度分析备选**：基于增强图像的列亮度分析，自动寻找最可能的编号区域
- **自适应二值化**：在编号区域内使用自适应阈值提取白色点阵字符

### 4. 点阵字符分割优化
- **垂直投影分析**：针对点阵字符特点调整空白列阈值
- **点阵特征过滤**：
  - 最小宽度：1像素（支持单列点阵）
  - 宽高比范围：0.005-0.5（支持窄高型点阵字符）
  - 最小面积：5像素（过滤噪声）
- **归一化处理**：保持原始宽高比，居中放置到64x64画布

## 设计理念

### 算法优先原则
- **基于规则**：优先使用基于图像特征的规则算法，减少对深度学习的依赖
- **模块解耦**：四个处理阶段完全独立，便于调试和优化
- **可解释性**：每个处理步骤都有明确的图像特征依据，结果可解释

### 鲁棒性设计
- **容错机制**：支持未找到编号区域、边界异常等情况
- **阈值自适应**：基于图像特征自动调整处理阈值
- **多策略备选**：主要策略失败时自动切换到备用策略

### 可扩展性
- **模块化架构**：易于添加新的处理阶段或替换现有算法
- **参数可配置**：关键处理参数可通过配置文件或API调整
- **结果可视化**：丰富的中间结果输出，便于算法调试

## 技术挑战与解决方案

### 挑战1：橡胶表面反光不均匀
- **解决方案**：采用CLAHE增强，提高局部对比度
- **效果**：有效增强白色点阵字符与黑色胎面的对比

### 挑战2：点阵字符断开不连续
- **解决方案**：垂直投影分析结合点阵特征过滤
- **效果**：准确识别单列点阵字符，过滤橡胶表面噪声

### 挑战3：编号区域位置多变
- **解决方案**：状态机扫描算法结合多阈值策略
- **效果**：在各种光照和位置条件下都能精确定位编号区域

### 挑战4：边界难以精确确定
- **解决方案**：黑白像素比例阈值结合经验扩展
- **效果**：像素级精度的边界定位，确保包含完整区域
