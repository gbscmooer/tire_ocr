# 轮胎OCR识别系统

一个基于计算机视觉的轮胎表面点阵字符识别系统，使用Python、OpenCV和投影波高匹配算法进行字符识别。

## 系统架构

该系统由三个核心模块组成：

1. **main.py**: 主控制流程，负责图像预处理和形态学操作
2. **ocr.py**: 字符识别模块，基于投影波高匹配算法
3. **post_vertical_projection.py**: 字符分割模块，使用垂直投影进行字符分段

## 文件功能分析

### main.py - 主处理流程

#### 核心功能
- **TireOCR类**: 橡胶胎面点阵字符识别主类
- **ROI提取**: 从原始图像中提取轮胎区域
- **图像预处理**: 二值化、形态学操作、图像增强
- **标签区域定位**: 定位编号区域
- **滴水算法**: 分离粘连字符

#### 数据流
1. **输入**: 原始图像 → 读取并存储为original_image
2. **二值化**: original_image → binary_image (Otsu阈值)
3. **ROI提取**: binary_image → 定位编号区域边界
4. **胎面区域**: 基于编号区域扩展定位胎面区域
5. **预处理**: 胎面区域 → 灰度化 + 二值化 + 90度旋转 → enhanced_image
6. **标签定位**: enhanced_image → label_binary (编号区域二值化图像)

#### 关键算法
- **ROI定位算法**: 从图像中心向左扫描，使用状态机识别编号区域和胎面区域
- **形态学处理**: 开运算去噪、膨胀连接字符、闭运算填充空隙
- **滴水算法**: 基于水平投影和水滴下落路径的字符分离算法

#### 耗时分析
- **ROI提取**: O(W×H) - 需要扫描整个图像宽度进行边界检测 (耗时: 30-40%)
- **形态学操作**: O(W×H×kernel_size) - 多次形态学变换 (耗时: 25-30%)
- **滴水算法**: O(W×H×peaks) - 在候选分割点上模拟水滴路径 (耗时: 15-20%)
- **图像旋转**: O(W×H) - 90度旋转 (耗时: 5-10%)
- **其他预处理**: O(W×H) - 二值化等操作 (耗时: 10-15%)

### ocr.py - 字符识别模块

#### 核心功能
- **投影计算**: 水平和垂直投影
- **峰值检测**: 基于导数符号变化的峰值查找
- **模板匹配**: 基于投影波高序列的字符识别
- **字符识别**: 使用Clist.txt模板进行KNN风格匹配

#### 数据流
1. **图像预处理**: 输入字符图像 → 灰度化 → 二值化
2. **投影计算**: 二值图像 → 水平投影(proj_x) + 垂直投影(proj_y)
3. **峰值检测**: 投影 → 平滑 → 寻找峰值 → 提取波高序列
4. **模板匹配**: 波高序列 → 与Clist.txt模板匹配
5. **结果输出**: 匹配结果 → 识别标签 + 置信度分数

#### 关键算法
- **投影波高匹配**: 通过计算字符的水平和垂直投影，提取波峰和波高序列
- **峰值检测算法**: 使用导数符号变化检测局部极值点
- **归一化匹配**: 将检测到的波高序列与模板进行归一化比较
- **误差计算**: 计算检测序列与模板之间的差异度量

#### 耗时分析
- **投影计算**: O(W×H) - 沿两个方向求和 (耗时: 20-25%)
- **峰值检测**: O(N) - N为投影长度，需平滑和导数计算 (耗时: 30-35%)
- **模板匹配**: O(P×T) - P为峰值数，T为模板数 (耗时: 35-40%)
- **结果处理**: O(1) - 简单赋值和输出 (耗时: 5-10%)

### post_vertical_projection.py - 字符分割模块

#### 核心功能
- **垂直投影**: 计算字符图像的垂直投影
- **峰值聚类**: 使用状态机将峰值分组为字符
- **字符切割**: 基于分组结果切割字符图像
- **识别接口**: 调用OCR模块进行字符识别

#### 数据流
1. **投影计算**: 字符图像 → 垂直投影数组
2. **峰值检测**: 投影 → 平滑 + 非线性增强 + 局部对比度增强 → 峰值列表
3. **字符分组**: 峰值 → 状态机分组 → 字符段列表
4. **字符切割**: 字符段 → 从原图切割字符 → 保存/返回字符图像
5. **字符识别**: 字符图像 → OCR模块 → 识别结果

#### 关键算法
- **高斯平滑**: 减少投影噪声，提高峰值检测准确性
- **非线性增强**: 使用gamma变换提升弱峰，压缩强峰
- **局部对比度增强**: 基于滑动窗口的对比度增强算法
- **状态机分组**: 基于峰间距和峰数量的字符分组策略

#### 耗时分析
- **投影计算**: O(W×H) - 垂直方向求和 (耗时: 15-20%)
- **高斯平滑**: O(N×kernel_size) - N为投影长度 (耗时: 20-25%)
- **峰值检测**: O(N) - 导数计算和零点检测 (耗时: 25-30%)
- **字符分组**: O(P) - P为峰值数量 (耗时: 15-20%)
- **字符切割**: O(C×W×H) - C为字符数量 (耗时: 10-15%)

## 系统配置参数

### main.py 配置
```python
# ROI边界扩展参数
expand_left: 0           # 向左扩展像素
expand_right: 40         # 向右扩展像素
min_width: 80           # 胎面区域最小宽度
max_width: 350          # 胎面区域最大宽度

# 形态学参数
stage2_open_kernel: (2, 2)          # 开运算核
stage2_dilation_kernel: (7, 9)      # 膨胀核
stage2_close_kernel: (9, 7)         # 闭运算核

# 字符分割参数
split_width_threshold: 35           # 字符宽度阈值
split_valley_ratio: 0.5             # 水平投影波谷阈值
```

### ocr.py 配置
```python
# 投影处理参数
PEAK_WINDOW: 2                      # 导数均值窗口大小
PEAK_MIN_HEIGHT_THRESHOLD: 0.05     # 最小峰值高度阈值
SMOOTH_KERNEL_SIZE: 5               # 高斯平滑核大小
SMOOTH_SIGMA: 0.8                   # 高斯核标准差

# 识别参数
MAX_RATIO_THRESHOLD: 2.0            # 波高比例阈值
SCORE_THRESHOLD: 15.0               # 识别阈值
```

### post_vertical_projection.py 配置
```python
# 投影处理参数
```

## 性能优化建议

### 耗时瓶颈分析
1. **ROI提取** - 占总时间的30-40%，可考虑优化扫描算法
2. **形态学操作** - 占总时间的25-30%，可使用并行计算
3. **峰值检测** - 占总时间的25-30%，可使用更高效的算法

### 优化方案
1. **并行处理**: 对多个字符同时进行识别
2. **缓存机制**: 缓存模板和中间结果
3. **算法优化**: 使用快速傅里叶变换进行投影计算
4. **内存优化**: 减少不必要的图像复制操作

## 使用说明

1. 将待识别图像放在项目根目录
2. 运行 main.py 进行预处理
3. 运行 post_vertical_projection.py 进行字符分割
4. 运行 ocr.py 进行字符识别
5. 识别结果保存在 output/characters/recognition_result.txt

## 文件依赖关系

```
main.py
├── 生成 output/3_enhanced.png (预处理图像)
└── 生成 output/morphology_result.png (形态学结果)

post_vertical_projection.py
├── 读取 output/3_enhanced.png 和 output/morphology_result.png
├── 生成 output/characters/ (分割的字符图像)
└── 调用 ocr.py 进行识别

ocr.py
├── 读取 Clist.txt 模板文件
└── 生成 output/characters/recognition_result.txt (识别结果)
```
