# 轮胎胎面点阵字符识别系统 (Tire OCR)

## 项目概述

本项目针对橡胶轮胎胎面上的白色点阵字符识别问题，实现了一套完整的传统计算机视觉解决方案。系统采用多阶段处理流程：ROI提取、形态学处理、垂直投影字符分割、HOG特征提取和KNN模板匹配，完成了从字符区域提取、字符分割到字符识别的完整流程。

## 总体技术栈

### 核心库
- **OpenCV (cv2)**：图像处理、二值化、形态学操作、HOG特征提取、连通域分析
- **NumPy**：数值计算、数组操作、投影统计
- **Matplotlib**：可视化、投影曲线绘制、结果展示
- **Python标准库**：os, sys, subprocess等

### 算法架构
- **传统图像处理**：不使用深度学习，完全基于传统CV方法
- **多阶段流水线**：模块化设计，每阶段输出中间结果便于调试
- **参数集中配置**：所有超参数通过CFG字典管理，便于调整优化

## 为什么用这些方法？

### 1. 点阵字符的特殊性
轮胎胎面字符由离散的白点组成，而非连续笔画，这带来以下挑战：
- 字符连通性差，直接轮廓检测会分割成多个小区域
- 背景噪声多（胎面纹理干扰）
- 字符方向特殊（逆时针旋转90度排列）

### 2. 传统方法的优势
- **可解释性强**：每个处理阶段可视化，便于调试和优化
- **计算效率高**：无需GPU，适合嵌入式或边缘设备
- **数据要求低**：无需大量标注数据训练深度学习模型
- **鲁棒性好**：针对特定场景优化，对光照变化有一定容忍度

### 3. 技术选择理由
- **垂直投影法**：针对旋转后水平排列的字符，投影能准确反映字符间距
- **形态学处理**：连接离散点阵成连续区域，便于后续分割
- **HOG特征**：对字符形状的梯度方向敏感，适合模板匹配
- **KNN模板匹配**：简单有效，无需训练复杂分类器

## 超参数详解

### tire_ocr.py 中的关键参数

#### ROI提取参数
```python
'expand_left': 0,           # 向左扩展像素
'expand_right': 40,         # 向右扩展像素
'min_width': 80,           # 胎面区域最小宽度
'max_width': 350,          # 胎面区域最大宽度
'expand_top': 20,          # 上边界扩展像素
'expand_bottom': 20,       # 下边界扩展像素
```
**影响**：控制胎面区域提取的边界，过小会截断字符，过大会包含过多背景噪声。

#### 形态学参数（Stage5 - 字符连通）
```python
'stage5_open_kernel': (5, 1),        # 轻量开运算去噪核
'stage5_open_iterations': 1,
'stage5_dilation_kernel': (1, 7),    # 垂直方向膨胀核
'stage5_dilation_iterations': 1,
'stage5_close_kernel': (1, 15),      # 垂直方向闭运算核
'stage5_close_iterations': 1,
'stage5_h_erosion_kernel': (3, 1),   # 横向腐蚀核
'stage5_h_erosion_iterations': 4,    # 横向腐蚀迭代次数
```
**影响**：控制点阵字符的连接程度。垂直核(`(1, 7)`, `(1, 15)`)重点连接垂直方向的离散点，横向腐蚀(`(3, 1)`)收缩字符宽度，增加字符间间隙。

#### 轮廓过滤参数
```python
'contour_min_w': 8,        # 轮廓最小宽度
'contour_min_h': 12,       # 轮廓最小高度
'contour_max_w': 90,       # 轮廓最大宽度
'contour_max_h': 60,       # 轮廓最大高度
'contour_min_area': 80,    # 轮廓最小面积
'contour_min_fill_ratio': 0.15,  # 最小填充比例
```
**影响**：过滤噪声轮廓，保留真正的字符区域。这些值基于字符实际尺寸设置。
